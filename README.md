# Python Heart Animation 💗

A glowing pink heart created with Python's Turtle graphics library using mathematical equations and randomized line strokes.

## Features

- Mathematical heart shape generation using trigonometric functions
- Randomized particles and line strokes
- Pink and purple color variations
- Layered inner heart and outer glow effects
- Progressive rendering animation

```bash
python heart.py
```

A Turtle graphics window will display the heart animation.
